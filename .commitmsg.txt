chore: default OTA address to localhost instead of the author's server

The site is public at wuchang.me, so a default pointing at the author's backend
meant every visitor silently connected to it. Replaced with

    http://localhost:8002/xiaozhi/ota/

which is xiaozhi-server's default local port -- the same target the upstream
default (http://127.0.0.1:8002/...) has. Anyone running a backend locally can
use it as-is; the site itself provides no public backend.

Changed in four places that hold a default:

  index.html               full app's OTA field
  diagnostics.html         self-check page's OTA field
  standalone/build.html    generator's default (two occurrences: the input
                           value and the fallback in build())
  standalone/index.html    regenerated from the template in build.html

Added inline guidance so a visitor is not left guessing why the default does
not work:

  - placeholder text on each OTA input
  - a note under the field on diagnostics.html and the standalone page:
    "这里要填你自己的后端。默认 localhost:8002 只在你本机跑着
     xiaozhi-server 时有效。"

Docs updated to match. NOTICE.md now records this honestly rather than as an
"upstream X -> ours Y" line: the default was the author's instance during
development for convenience, and reverted to the local default once the site
became public.

Removed the last author-server reference from NOTICE.md entirely, so the repo
contains no xiaozhi.xiada.cn or server IP strings at all.

Verified by rendering each page in headless Chrome after serving the tree:

  full app        value=http://localhost:8002/xiaozhi/ota/  ✓
  diagnostics     value=http://localhost:8002/xiaozhi/ota/  ✓
  standalone      value=http://localhost:8002/xiaozhi/ota/  ✓
  generator       value=http://localhost:8002/xiaozhi/ota/  ✓
  hints rendered  on diagnostics, standalone and generator   ✓
  old address     absent from all four pages                 ✓

Also re-scanned the whole tree for sensitive strings -- the API key, LLM token,
DeepSeek key, SSH password, GitHub PAT, server IPs and the old hostname are all
absent.
