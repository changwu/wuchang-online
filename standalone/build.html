生成单文件版

把 libopus.js + app.js 打成一个可独立分发的 HTML
↓ 下载 index.html
生成的文件约 840KB，包含内联的 Opus 编解码器，不请求任何外部资源。
上面填你自己的后端地址。默认 localhost:8002 只在 本机跑着 xiaozhi-server 时有效；分发给别人前记得改成对方能访问的地址。
为什么需要页面来做这件事：项目部署在 GitHub Pages 上， 只能跑静态文件，不能跑 Python/Node 脚本。所以构建步骤搬到了浏览器里： 用 fetch 读取同源的 libopus.js 与 app.js，拼装后用 Blob 下载。

如果页面上打开（而不是 file://）才能 fetch 同源文件。
